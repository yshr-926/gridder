# グリッドベース簡易作図Webアプリケーション 仕様書

## 1. 概要
本ドキュメントは、ブラウザ上で矩形や凹凸のある形状を直感的に作成・配置できる簡易作図ツールの仕様を定義するものである。ユーザーはグリッド（方眼）を塗りつぶすことで任意の形状を作成し、それらをオブジェクトとして自由に配置・レイアウト検討を行うことができる。

## 2. 目的・コンセプト
*   **目的**: アイデア出し、簡易的なレイアウト検討（部屋、棚、会場配置など）を迅速に行う。
*   **コンセプト**: ログイン不要ですぐに使える、シンプルでミニマルな作図ツール。

## 3. ターゲット・ユースケース
*   **ターゲット**: 厳密なCADを使うほどではないが、寸法を意識した配置図や概念図を作りたいユーザー。
*   **主な用途**:
    *   部屋の模様替えや家具の配置シミュレーション
    *   イベント会場のブース割り当て
    *   DIYのための簡易設計図作成

## 4. システム構成
*   **プラットフォーム**: Webアプリケーション（PCブラウザ推奨）
*   **ユーザー管理**: ログイン機能なし（ゲスト利用のみ）
*   **データ保存**:
    *   ブラウザ完結型（サーバー側にユーザーデータを保存しない）
    *   一時保存にはブラウザのローカルストレージを使用可能とする

## 5. 機能要件

### 5.1. キャンバス・グリッド機能
*   **グリッド表示**: 画面全体に方眼状のグリッドを表示する。
*   **実寸スケール設定**:
    *   ユーザーは「1マス ＝ 〇〇 cm (または m, mm)」のように、グリッドの実寸スケールを定義できる。
    *   画面上に現在のスケール（例：1マス = 10cm）を表示する。
*   **キャンバス操作**:
    *   キャンバス全体のズームイン・ズームアウト（拡大縮小）。
    *   キャンバスのパン（視点移動）。

### 5.2. 作図・編集モード（ツール切り替え方式）
画面上のツールバーにて、以下のモードを明確に切り替えて操作する。

#### A. 描画モード（鉛筆ツール）
*   **操作**: グリッド上のマスをクリック、またはドラッグすることでマスを「塗りつぶす」。
*   **形状生成**: 連続して塗りつぶされた領域を「1つの図形オブジェクト」として生成する。
*   **消しゴム**: 塗りつぶしたマスを個別に消去する機能（オブジェクト確定前の修正用）。

#### B. 選択・移動モード（矢印ツール）
*   **オブジェクト選択**: 作成済みの図形オブジェクトをクリックして選択状態にする。
*   **移動**: 選択したオブジェクトをドラッグ＆ドロップでグリッド単位で移動させる（スナップ機能）。
*   **回転**: オブジェクトを90度単位で回転させる。
*   **削除**: 選択したオブジェクトをキャンバスから削除する。
*   **複製**: 選択したオブジェクトをコピー＆ペーストする。

### 5.3. データ管理・入出力
*   **プロジェクト保存（エクスポート）**:
    *   **専用データ形式 (.json)**: 現在のキャンバス状態（図形の配置座標、スケール設定など）をJSONファイルとしてダウンロード可能にする。これにより作業の再開を可能にする。
*   **画像書き出し**:
    *   **画像形式 (.png / .jpeg)**: 現在のキャンバスの見た目を画像ファイルとしてダウンロード可能にする。資料作成や共有用。
*   **データ読み込み（インポート）**:
    *   保存した専用データファイル(.json)をドラッグ＆ドロップまたは選択して読み込み、前回の続きから作業を再開できる。

## 6. UI/UXデザイン要件
*   **デザインテイスト**: **シンプル・ミニマル**
    *   白、黒、グレーを基調とした、装飾を削ぎ落としたプロフェッショナルな外観。
    *   機能美を重視し、ユーザーが作図作業に集中できる画面構成とする。
*   **レイアウト**:
    *   メインエリア：広大なキャンバス
    *   ツールバー：画面端（左または上）に固定。「描画」「移動」「消しゴム」などのアイコンを配置。
    *   プロパティエリア：スケール設定やエクスポートボタンなどを配置。

## 7. 非機能要件
*   **レスポンス**: 描画や移動操作において、ラグを感じさせないスムーズな動作（Canvas API等の高速な描画技術の採用を想定）。
*   **ブラウザ互換性**: Google Chrome, Firefox, Safari, Edgeの最新版で動作すること。

## 8. 技術選定
*   フレームワーク: React 18+
*   言語: TypeScript
*   描画ライブラリ: Konva.js (react-konva)
*   スタイリング: Tailwind CSS
*   ビルドツール: Vite
