# Triage Labels

各スキルは、以下の5つの標準トリアージ役割を使用する。このファイルでは、その役割をリポジトリの Issue tracker で実際に使用するラベル文字列に対応付ける。

| mattpocock/skills のラベル | このリポジトリのラベル | 意味 |
| -------------------------- | -------------------------- | ---- |
| `needs-triage` | `needs-triage` | メンテナーによる Issue の評価が必要 |
| `needs-info` | `needs-info` | 報告者からの追加情報を待っている |
| `ready-for-agent` | `ready-for-agent` | 仕様が明確で、AFK agent が実装可能 |
| `ready-for-human` | `ready-for-human` | 人による実装が必要 |
| `wontfix` | `wontfix` | 対応しない |

スキルが役割を指定した場合（例:「AFK-ready のトリアージラベルを付ける」）、この表で対応するラベル文字列を使用する。

実際の運用で異なるラベル名を使用する場合は、中央の列を変更する。
