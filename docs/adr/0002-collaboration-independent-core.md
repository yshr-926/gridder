# 共同編集から独立したエディタコアを先に作る

初回リリースでは、通常の TypeScript ドキュメントモデルとコマンド履歴を編集状態の正規ソースにする。Yjs はコアへ直接組み込まず、共同編集を再導入する段階で Adapter として接続する。これにより単独編集の操作設計とデータモデルを先に安定させ、ネットワーク・競合解決・永続化の複雑さを初回リリースの必須経路から外す。

初回リリースはバックエンドなしで動作させる。現在の Rust バックエンドは共同編集専用であり、活動中のアプリ構成から外すが、この判断だけを理由に別言語へ書き直さない。共同編集を再開するときに要件を定義し直し、Yjs エコシステムとの親和性から TypeScript を第一候補として技術選定を行う。

新しい設計と競合する Rust 共同編集サーバー、Yjs 文書 Adapter、共同編集 UI は、新しいエディタコアへ再利用できる Interface とテストを選別した後にリポジトリから削除する。履歴保存を目的とした `archive/` は作らず、必要な場合は Git 履歴を参照する。
