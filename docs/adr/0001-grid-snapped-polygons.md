# グリッド頂点ポリゴンを図形の正規モデルにする

> 補足: セルの追加・削除による形状編集は [ADR-0006](0006-shape-boolean-operations-replace-cell-editing.md) で図形どうしの結合・くり抜きに置き換えた。本記録のうち「セルの追加・削除は正方形との論理和・差として反映する」という部分はその ADR が上書きし、それ以外（ポリゴンを正規モデルにすること、論理演算を Adapter 越しに使うこと、非連結結果の分割、変形と回転の規則）は引き続き有効である。

Gridder のすべての閉じた図形は、グリッド頂点にスナップするポリゴンとして保持する。矩形は4頂点のポリゴンを作る直接操作とし、自由形状は図形どうしの論理和・差として同じポリゴンへ反映する。これにより真っすぐな斜辺とグリッド単位の自由形状を両立し、矩形とポリゴンで選択・変形・重なり順・書き出しの規則が分岐することを避ける。

ポリゴンの論理演算は実績ある permissive OSS を薄い Adapter の内側で利用する。エディタコアは特定ライブラリの型を公開せず、Gridder の座標・図形型と演算結果だけを扱う。自前の幾何アルゴリズムは実装しない。

差演算によって図形が複数の非連結領域へ分かれた場合は、それぞれを独立した図形にする。穴が開いただけの場合は、一つの図形が内周を持つ形として保持する。分割全体は一つの Command とし、Undo では元の図形へ戻す。

矩形は選択中に表示する辺・角のハンドルで伸縮する。矩形以外のポリゴンは頂点または辺を直接動かして変形し、バウンディングボックスによる比例拡大・縮小は行わない。図形の回転は 90 度単位に限定し、回転後もすべての頂点をグリッド上に保つ。
